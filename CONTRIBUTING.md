# Contributing

Thanks for your interest in contributing to this project.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes and test them locally.
4. Submit a pull request with a clear explanation of the update.

## Project setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python server.py
```

## Code guidelines

- Keep the code clean and readable.
- Avoid committing unnecessary files or generated output.
- Include comments where the logic is not obvious.
- Use a clear commit message for each change.

## Issues

Please open an issue before starting major changes so the scope and approach can be discussed.
